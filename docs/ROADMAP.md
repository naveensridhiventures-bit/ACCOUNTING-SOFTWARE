# Roadmap

- [x] Phase 0: foundation (API skeleton, auth, config, logging, errors, health)
- [x] Phase 1: accounting core (groups, ledgers, vouchers, reversal, trial balance, ledger statement, DB-level integrity)
- [x] Phase 1b: users and roles admin, financial-year create/close/re-open, ledger edit/hide/delete
- [x] Phase 2: customers and suppliers (ledger-backed), products and services, stock movements, weighted-average valuation
- [x] Phase 3: sales invoices, purchase bills, credit/debit notes, receipts and payments with allocation, outstanding and ageing
- [x] Phase 4: profit and loss, balance sheet, cash and bank, stock valuation, year-end closing
- [x] Phase 5: GST (CGST/SGST/IGST, place of supply, round-off, GST summary, HSN summary)
- [x] Phase 6: dashboard, expenses, bank transfers, bank reconciliation, audit log viewer, document number prefixes
- [x] Phase 8 (part): React frontend for all of the above
- [ ] Next: multiple warehouses, batch/expiry, recurring invoices, quotations and purchase orders, e-invoice / e-way bill export, PDF email, multi-currency, budgets, bank statement import, deployment scripts and backups
